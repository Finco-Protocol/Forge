## Environment limits of this development sandbox (stated, not hidden)
No Docker daemon is available here, so `docker-compose.staging.yml` can be linted and statically checked but **not executed** here (CI runners have Docker; the compose smoke job is `NOT_EXECUTED_HERE`). The process-based orchestrator (`scripts/w06/staging-stack.ts`) runs the same topology (PostgreSQL 16, Anvil, simulated GitHub, migrate, web, worker) with real separate OS processes and is what the local acceptance evidence comes from.
