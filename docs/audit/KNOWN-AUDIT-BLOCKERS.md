## What a green CI result means here

`ENGINEERING_PASS` means "every Class A item that was executed passed" and is always reported together with `PRODUCTION_BLOCKED`. It is capped by deferred items (`A07e`), so a run can be `EVIDENCE_INCOMPLETE`. It is not an approval and not a readiness claim.
